# 🎮 Tic-Tac-Toe Game (Java Console Version)

A simple yet flexible Tic-Tac-Toe game built using Java. Supports **any board size** (NxN) and lets you play against another human or a basic computer opponent.

---

## 🚀 Features

- 🧱 Custom board size (e.g., 3x3, 4x4, etc.)
- 👤 Player vs Player mode
- 🤖 Player vs Computer (random AI)
- 🔍 Win checking across rows, columns, diagonals
- 🚫 Input validation for safe gameplay
- 🧼 Clean console UI and modular code

---

## 🛠️ Tech Stack

- Java
- Object-Oriented Programming (OOP)
- Scanner for input handling

---

## 💻 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/indhresh-01/Tick-Tack-Toe.git
   cd Tick-Tack-Toe
   ```

## 🧠 How It Works
- Players take turns marking the board with 'x' and 'o'.

- Win is detected if any row, column, or diagonal has all the same marks.

- Game ends in a win or a draw.
